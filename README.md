# ClearPath

ClearPath is a local-first Expo React Native CBT wellness companion. It includes a crisis reflection flow, daily CBT training, a journal, a learn library, and device-local settings.

## Run

```bash
npm install
npm run start
```

## Safety Notes

ClearPath is a self-help wellness tool and is not a substitute for professional mental health care. Crisis resources are intentionally available from the home screen and throughout high-distress crisis flows.

## Kiro

Kiro steering files live in `.kiro/steering/`. The local Kiro CLI is available at `/home/elst/.local/bin/kiro-cli-chat`, but it must be logged in before spec delegation can run.
